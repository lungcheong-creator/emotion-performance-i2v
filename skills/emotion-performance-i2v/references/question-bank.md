# 選項式導演訪談題庫

用法：從各區塊挑選，組成一輪不超過 4 題的 `AskUserQuestion`。**第一個選項為推薦**，並在 description 裡說明選擇的代價與效果。

## 輪次配置（2026-09-25 起）

| 輪 | 題目 | 說明 |
|---|---|---|
| **前置** | 素材體檢（Stage 0）→ 劇照讀解（Stage 0.2）→ **靈感採集 N（Stage 0.6）** | 讀解是**回讀**，不佔題額；N 在 Stage 0.6 單獨問（每張圖一次） |
| **第一輪** | **A 情緒方向 ＋ 前情子題** | 選項由讀解現生成；前情要扣著 N 採集到的原話 |
| **第二輪** | **O 生視頻模型 ＋ P 時長 ＋ B 表演幅度** | 三題一起。都是技術／規格決策 |
| **第三輪** | **G 聲音設計**（必問 4 題：**G0 路徑** ＋ G1 環境音 ＋ G2 配樂 ＋ G3 人聲） | 選了人聲才**另開一問**追 G4 對白內容與落點（那時已有節拍表可用） |
| **第四輪** | **Q 主體與景別**（條件觸發）＋ C／D／E／F 裡挑 2–3 題 | 視需要 |

一輪最多 4 題。塞不下時優先保住 **O 與 P**（決定技術可行性上限），再保 **A**。
用戶若已回答過的維度，不要重複問。用戶說「你決定」時，依默認值往下走並在設計書標註是默認決定。

選項文字要能讓非專業用戶一眼選出來，但 description 用表演學語言，讓他知道自己選了什麼。

## O · 生視頻模型與模式（必問，無預設）

問法：「這次用哪個生視頻模型？」（**不預設，每次都問**）

| 選項 | 標籤 | description |
|---|---|---|
| O1 | kling-3.0/video | 單張首幀 → 動態。最穩、已驗證多次，支援負面提示詞 |
| O2 | kling-3.0-omni/image-to-video | 單張首幀 → 動態。原生 1080p/4K、可加音訊 |
| O3 | kling-3.0-omni/reference-to-video | 多張參考圖（人物／服裝／場景）或參考影片 → 動態 |

若選 O3，**追問子題 O3b**：「有幾張參考圖、各鎖什麼？」
- 單圖鎖人物（最常見）
- 人物 + 服裝
- 人物 + 服裝 + 場景
- 另含參考影片

O3 已配置專用 key 並驗證授權；**參考圖上限 7 張**，人物圖為事實必備。
O2 與 O3 的 `aspect_ratio` 規則**相反**，提問時要講明白（否則用戶會以為 16:9 隨手可得）：

- **O2 `omni-image`**：單鏡頭下**只能送 `auto`**（送 `16:9` 直接 422 失敗），輸出比例**繼承輸入圖**。
  所以要 16:9，**必須在生成前用 `scripts/normalize_16x9.py` 把參考圖正規化成 16:9** —— 這是硬前置，不是保險。
- **O3 `omni-reference`**：`aspect_ratio` **必須寫死具體比例**（送 `16:9`；送 `auto` 會 500）。輸入圖仍建議一併正規化，但守住比例的是請求參數。

兩者都**顯式送 `resolution: "1080p"`**（API 預設 720p，會靜默降級）。

## P · 時長（必問，無預設）

問法：「這支要幾秒？」（**不預設，每次都問**）

**為什麼這題必須問**：時長不是滑桿，它決定**節拍摺疊到哪一段**。
同一個情緒在 5s 是完整的，在 15s 會鬆掉——除非照 `performance-lexicon.md` §7.3 重新配拍。

| 選項 | 標籤 | 節拍 | description（要讓用戶知道選了什麼） |
|---|---|---|---|
| P1 | **8 秒（推薦）** | 2 拍 | 甜蜜點。能容納「鋪墊 → 停頓 → 轉折 → 懸置」的完整呼吸，情緒站得住又不拖 |
| P2 | 5 秒 | 1 拍 | 社群主力。單一轉折，資訊密度最高。**沒有停頓拍**，所以敘事性來自「換招」而非鋪墊 |
| P3 | 10 秒 | 3 拍 | 有敘事弧才用。多一個**回收拍**收乾淨 |
| P4 | 15 秒 | 4 拍 | 需要明確多拍敘事時才用。低幅度表演在 15s 很容易變成「什麼都沒發生」，生成時間與費用也最高 |

**提問時務必一起講清楚的三件事：**

1. **節拍數會跟著變**：選 10s 不是把 8s 拉長，而是多一個停頓拍與一個回收拍。節奏由 skill 負責，用戶只選秒數。
2. **成本**：時長越長，生成時間與費用越高（5s 實測約 2m20s）。Kie 帳戶的實際計費請用戶自行確認。
3. **風險**：10s 以上的成敗取決於**停頓拍寫得好不好**。停頓拍寫成「留空」→ 模型自己加戲（多餘眨眼、嘴動）、拖慢成慢動作、或把同一動作做兩次。對策見 `performance-lexicon.md` §7.4。

**若用戶選 P3 / P4，追問子題 P3b**：「要用哪一種停頓拍的內容？」
- 只有呼吸與一次眨眼（最克制，推薦）
- 加上環境流動（風、光線位移、懸浮塵埃）
- 加上一個不自主的小動作（吞嚥、指尖微動——**手部有畫壞風險**）

**技術邊界（可如實告知）**：三個模型的 `duration` 都是 **3–15 秒**（2026-09-25 實測）。
超出範圍會**直接報錯，不會靜默縮短**。

## N · 靈感採集（**每張圖單獨問**，前置 Stage 0.6）

問法：「這張圖你是怎麼看到的？當初為什麼留下它？」

**為什麼要問**：最終成片必須貼合你最初看到這張圖的那個念頭。
不採集，最後就只能交付一個「很電影感的悲傷女子」——那誰都能做。

**採集方式**：`AskUserQuestion` 給四個方向讓你好回答，但**請盡量用自己的話寫**（選項只是引子）。
用戶選完後**追問一句**，把原話記進溯源表：

| 選項 | 標籤 | 追問 |
|---|---|---|
| N1 | 我看到一個**瞬間**（推薦） | 那個瞬間是什麼？她正在做什麼、剛剛發生了什麼？ |
| N2 | 我聽到一首歌／讀到一段文字 | 哪一首、哪一句？**把原文記下來**（它會決定整支片的節奏與用詞） |
| N3 | 我想要一種**感覺** | 哪一種？用一個形容詞或一個身體感覺描述 |
| N4 | 我就是覺得這張圖好看 | 跳過追問。讀解全權決定，設計書註明「無額外意圖輸入」 |

**記錄規則**：把用戶的原話**逐字**寫進設計書的溯源表（見 `prompt-templates.md` §7），
後續每一個設計決定都要能指回某一句原話。**沒有被用到的原話要顯性列出並說明原因。**

**多圖批次**：如果一次跑多張圖，這題**每張圖各問一次**，不共用答案。

## A · 情緒方向（必問，選項由讀解現生成）

問法：「這幾種可能裡，哪一種最接近你要的？」

**這題的選項不是從表裡抄的，是為這張圖現做的。**生成步驟：

1. 從讀解拿到「這張圖正在發生的動詞」與三條推定前情（`visual-analysis.md` §4.3）
2. 從 `acting-logic.md` §4 的 **15 族**裡選出**與畫面相符的 3–4 族**
3. 每族的 description 必須寫上**這一族要用畫面裡的哪個元素**（例如「用左側的留白承接她的視線」）
4. **候選必須橫跨極性**——見下方硬規則

> **⚠️ 硬規則：候選至少要有一個正向族（F-12~F-15）與一個負向族**
>
> 這是防止「隱形壓抑預設」回流的機制（2026-09-26 加入）。
> 舊版的讀解→選族流程**系統性地**只會產出負向選項，因為族群全落在負向到中性，
> 而 agent 又傾向選「符合畫面張力」的那幾族。結果是任意素材都被導向壓抑，且看不出來。
>
> **只有一個正當的例外**：這張圖**確實**只支持負向演繹（例如首幀已在明顯的悲傷中、
> 前情是失去）。此時**照常只給負向選項，但在 Gate 1 明寫為什麼**——
> 「顯性排除」可以，「默默排除」不行。

**選項範本（以「車內、通話剛結束、低光」的圖為例，示意格式）：**

| 選項 | 標籤 | description（表演學含義 + 用到畫面的什麼） |
|---|---|---|
| A1 ★推薦 | **壓抑系**：想哭但忍住 | 情緒在臨界點下方。靠吞嚥、繃下唇、視線下垂傳達。**用右側車窗的光當她唯一的光源**，壓低調性。**收尾不帶笑** |
| A2 | **釋然系**：正在放下 | 剛結束一件耗盡她的事。用一次完整深呼吸與肩膀落下收尾。**用畫外空間暗示電話那頭已經不在**。**收尾嘴角放平** |
| A3 | **警覺系**：忽然察覺 | 手上的動作停在半途，頭微側聽。「她還沒反應過來」的延遲感。**收尾不帶笑** |
| A4 | **安心系**（正向）：被接住、放心 | 通話之後確認了對方還在。先深吸一口氣，讓肩膀真的落下去，眼神變軟。**用車艙的密閉感當「被包住」的空間隱喻**。**收尾笑意不收** |

> 注意 A4：同一張圖、同一個前情，**正向族讓這一輪的選項不再是四選一的悲傷變體**。
> 這就是極性橫跨規則要達到的效果。

**15 族完整清單**（選用哪幾族進選項，依畫面判斷）：

| 極性 | 族 |
|---|---|
| 負向／內斂 | 壓抑系 · 期待系 · 釋然系 · 警覺系 · 好奇系 · 內斂憤怒系 · 疲憊系 · 溫柔系 · 決心系 · 挑釁系 · 追憶系 |
| **正向** | **喜悅系 · 得意系 · 安心系 · 玩心系** |

各族內容見 `acting-logic.md` §4。**description 請一併寫出「這一族收尾允不允許帶笑」**，
讓用戶知道自己選的不只是情緒，還有結尾的表情。

**前情子題 A5（與 A 同輪或緊接追問）**：「她剛剛經歷了什麼？」
讀解 §4.3 已生成三個互斥的前情，做成選項。**前情決定整支片的戲**，不要跳過。

補充：若用戶選「你決定」，依讀解的姿態與色調推斷，並在設計書標為默認決定。
**預設不要自動落到負向族**——若畫面支持正向讀法，「你決定」時應至少在其中一個正向族上標 ★推薦。

## B · 表演幅度（必問，取代舊版「克制」硬規則）

問法：「情緒要外顯到什麼程度？」

| 選項 | 標籤 | description |
|---|---|---|
| B1 ★推薦 | **克制** | 情緒在臨界點下方，只有 1–2 個訊號（眉／唇／喉結的微動、一次眨眼）。小螢幕上越細越真，觀眾會自己補完 |
| B2 | **標準** | 情緒浮出表面，不必費力就讀得到。加上肩線、頸部、重心與明確的視線轉移。**需要在 3 秒內被讀懂時選這個** |
| B3 | **強烈** | 情緒壓過控制。加上呼吸失控（吸氣抖一下）、身體前後位移、手臂整體角度變化。適合衝突與轉折段落 |
| B4 | ~~潰堤~~ | **不建議**。落淚、掩面、放聲哭——Kling 呈現不可靠且滑向狗血。要強度請選 B3 |

**三檔共同的硬邊界**（與幅度無關）：落淚／掩面／大笑／精細手部／快速複雜動作，
一律改用替代方案（見 `acting-logic.md` §5）。這不是你選得大就能做到的問題。

**幅度要跟時長配**：15s 建議 B2 以上；5s 用 B1 或 B2。
B3 在 15s 必須走全套節拍，否則會變成「一直很激動」的直線。

## Q · 主體與景別（**條件觸發**，讀解判定後自動帶入）

不是每張圖都要問。依 `visual-analysis.md` §6 的類型判定，命中才問：

| 觸發條件 | 問法 | 選項 |
|---|---|---|
| 讀數 `significant_blobs` > 1（**多人**） | 「這張圖裡誰是主角？」 | Q1 最靠前的／Q2 最亮的／Q3 最清楚的／Q4 我指定（附圖說） |
| 膚色區 < 18%（**全景／遠景**） | 「人物比較小，怎麼處理？」 | Q1 收緊成近景再生成（推薦，微表情才看得見）／Q2 保留全景，表演交給姿態與環境／Q3 保留全景並靠運鏡推近 |
| 側臉／背影（**B / C 類型**） | 「要不要讓她轉過來？」 | Q1 不轉，表演交給肩線與呼吸（推薦，零換臉風險）／Q2 只轉一點點（≤20°，中風險）／Q3 明顯轉頭（**高風險**，等於要求模型生成整張臉） |
| `skin_region` 為 null（**無人物**） | 「這張圖沒有清楚的人物，要走哪條路？」 | Q1 換圖／Q2 改走環境敘事（光線推移、焦點轉移）／Q3 只做環境空鏡 |

**多人素材的硬規則**：必須用景深、光線或構圖把主角確立起來（寫進提示詞），
否則模型會把注意力分散到第二個人身上。

---

> **區塊順序說明**：本節 C–F 屬**第四輪**。第三輪的 **G 聲音設計**寫在本節之後，
> 但實務上要先問 G（聲音）再問本節——聲音那題的答案會影響運鏡與環境的取捨。

## C · 動作譜（第四輪）

問法：「她的身體要做什麼？」

| 選項 | 標籤 | description |
|---|---|---|
| C1 ★推薦 | 呼吸與眨眼 | 唯一 100% 可靠的表演層。一次緩慢眨眼 + 胸口起伏，其餘交給環境 |
| C2 | 視線轉移 | 看鏡頭 → 垂眼 → 望向畫外遠處（視線是情緒的軌跡，最容易被讀懂） |
| C3 | 手部小動作 | 握緊又鬆開手機／指尖捏住圍巾邊緣。**風險**：Kling 手部細節弱，手指易變形 |
| C4 | 髮絲與衣料 | 被動動作（風帶動）。最安全，且能暗示環境存在 |

可多選。推薦組合：C1 + C2（+ C4）。
**背影／側臉素材**：C1 與 C4 是主力，C2 與 C3 不可用（看不到臉、手在畫外）。

## D · 運鏡與時間感（第四輪）

問法：「鏡頭怎麼看她的情緒？」

| 選項 | 標籤 | description |
|---|---|---|
| D1 ★推薦 | 緩慢推近 | 距離縮短 = 親密感上升，觀眾被拉進她的內心。最適合單人情感戲 |
| D2 | 弧形環繞 | 90–120° 弧線。她靜、世界動，適合表達「被時間遺落」。超過 120° 換臉風險升高 |
| D3 | 緩慢橫移 | 起幅在她 → 移向環境。適合有敘事對比物（窗外、街上）的構圖 |
| D4 | 定機呼吸感 | 機位幾乎不動，只有極輕微手持晃動。最極簡，張力全靠表演與環境 |

一律保持：一個速度、不變速、不晃動。

**選 D 之前先看讀數的景別**：全景／遠景素材建議配 D1（順便把主體收緊）；
已有淺景深的特寫建議配 D4（推近會爆框）。

## E · 環境敘事對比（第四輪）

問法：「什麼在替她說話？」

**先核對讀數的 `background.kind`**——環境裡沒有可動元素時，不要給不存在的選項。

| 選項 | 標籤 | description | 讀數對應 |
|---|---|---|---|
| E1 ★推薦 | 加速的人流 | 她慢世界快，時間被快轉。社群短片辨識度最高的一招 | `luma_std` > 45（結構密集） |
| E2 | 光影流動 | 雲影／車燈緩慢掃過。最安全，且強化寫實質感 | 任何背景都可用 |
| E3 | 風與粒子 | 髮絲、塵埃、細雨。低成本高回報的空氣感 | 有髮絲／衣角可見時 |
| E4 | 環境全靜 | 世界也停住了。孤獨感最強，但畫面容易死 | `luma_std` < 22（高度均勻） |

## F · 開頭與結尾處理（第四輪）

問法：「怎麼進、怎麼出？」

| 選項 | 標籤 | description |
|---|---|---|
| F1 ★推薦 | 靜止起幅 → 轉折 → 定格 | 0–1s 交接原圖構圖，情緒轉折，收停。有呼吸感 |
| F2 | 已在情緒中 | 開場即是最強點，收在靜止。更冷、更硬。**注意**：這等於放棄入戲拍的「目標已在場」鋪墊 |
| F3 | 收尾淡出 | **不建議**。淡出等於幫觀眾收情緒，情感片要留懸置 |

## G · 聲音設計（第三輪必問 3 題）

完整方法見 `references/sound-design.md`。**先講清楚兩條路徑，再問選項**：

> 「Kling 3.0 **原生**就會出聲音——環境音、配樂，還有**對得上的口型對白**，
> 都在同一次生成裡完成，不用後期。代價是貴約 43–50%（pro 無音 18 → 有音 27 credits/秒）。
> 想要完全可控（指定曲目、指定配音員、多語版本）才走後期鋪。」

**默認推薦原生。**只有在需要精確控制時才建議後期。

### G0 · 交付路徑（必問）

問法：「聲音走哪條路？」

| 選項 | 標籤 | description |
|---|---|---|
| S1 ★推薦 | **原生（Kling 3.0 同次生成）** | 環境音／配樂／**口型同步的對白**一次出。最快、最省事。**貴約 43–50%** |
| S2 | **後期全鋪** | 模型不出音（`sound: false`）。完全可控：指定曲目、指定配音員、多語版本。但要多一道工序 |
| S3 | **混合** | 環境音走原生（順手），配樂與人聲走後期（要可控）。**有對白時建議這個**——原生配樂音量不可控，容易蓋過台詞 |
| S4 | **完全無聲** | 交付靜音母版，聲音之後再說 |

**問完路徑後，G1／G2 的問法不變，但要說明「這一段是原生出還是後期鋪」。**

### G1 · L1 環境音內容（≥3 個選項，**由讀解現生成**）

**硬規則：每個選項都要指得出畫面的哪個元素。** 禁止給「溫暖的城市夜晚」這種與畫面無關的選項。

生成步驟：
1. 取 `read_frame.py` 的 `acoustic_hint`（收音距離／開闊度／密度／時間感）當底色
2. 取讀解的可動元素清單（`visual-analysis.md` §3）當具體音源
3. 組出 **3–4 個音場方案**，每個的 description 都要寫**畫面依據**

**範例（車內、夜、低光、近距離、窗上反光）：**

| 選項 | 標籤 | description |
|---|---|---|
| L1-A ★推薦 | 城市夜間底噪 ＋ 週期性車流 | 依據：讀數「密閉（上方暗且被遮）」＋「低光」＋背景結構密集。車流由遠及近再遠去 |
| L1-B | 只留下呼吸與布料摩擦 | 依據：「近距離（淺景深＋主體佔畫面大）」→ 呼吸在收音範圍內。最私密 |
| L1-C | 隔著玻璃的遠處雨聲 | 依據：車窗玻璃反光。雨在玻璃外，聲音隔一層，帶悶感 |
| L1-D | 我自己指定 | 直接描述你想要的聲音 |

**原生路徑的關鍵寫法**：把選中的音源**寫進提示詞**才會顯著
（`the rain hammers the tin roof` 比只寫「下雨的場景」強得多）；
要壓低環境音就加 `quiet` / `silent` / `hushed`。

**加分項**：`distance` 為「近距離」時，主動建議把呼吸鋪進環境音——
近距離的呼吸聲比任何音樂都有效，而且和表演的停頓拍天然同步。

### G2 · L2 配樂（必問，可與 G1 合併成一題）

| 選項 | 標籤 | description |
|---|---|---|
| M1 ★推薦 | **不指定，交由模型判斷** | 場景暗示音樂時 Kling 會自己生成。最快；但不可控 |
| M2 | **極簡 drone（後期）** | 大提琴／合成器低頻長音，不解決。承擔「時間感」，完全不搶表演 |
| M3 | **稀疏單音（後期）** | 鋼琴／吉他單音，60–68 BPM 小調。單音之間留大量空白 |
| M4 | 我自己指定 | 曲名／風格／情緒。有參考曲就記進溯源表 |

**必須告知的限制**：原生配樂**不能指定曲目、BPM 或調性**；生成的是原創音樂（無版權問題），
品質適合當背景、不是製作級配樂。**有對白時建議 L2 走後期**，才能把配樂壓到 −18dB 以下並讓出氣口。

### G3 · L3 人聲（必問）

問法：「要不要有人聲？」

| 選項 | 標籤 | description |
|---|---|---|
| V1 ★推薦 | **無聲** | 完全沒有人聲。**5s 低資訊量時的首選** |
| V2 | **畫外旁白** | 她沒開口，聲音從畫外來。敘事上常更強——觀眾聽到的是她的內心，不是她的嘴 |
| V3 | **畫內對白（含口型同步）** | 她真的開口。**Kling 3.0 的強項**，約 90% 幀對齊。風險在**首字與尾字最容易飄** |
| V4 | **我自己寫一句** | 你在下面直接填內容，我照長度上限檢查 |

**問這題時要一起講清楚三件事：**
1. **V3 是原生能力，不是後期假裝的**——但首字尾字會飄，所以台詞要短。
2. **對白有字數硬限**（見 G4），超過**直接拒絕建單**，不是提醒。
3. **多鏡頭想用同一個聲音** → 可以給 5–30 秒的音訊樣本鎖音色（`--voice-ref`，**只有 kling 支援**）。

### G4 · 對白內容與落點（**條件觸發**：G3 選 V2／V3／V4 才問）

**做法：由讀解生成 3 個候選台詞當選項，並開放用戶自行輸入**（選項之外的自由輸入欄就是自定義）。

生成規則：
1. 從讀解拿到「這張圖正在發生的動詞」與三條推定前情
2. 從情緒方向族（`acting-logic.md` §4）拿該族的**內在動作**——對白必須符合它
3. 三個候選要**互斥**（三種不同處境），不是同一句的三種說法
4. **每個候選都要標字數**，並落在上限內

**範例（壓抑系、8s、前情「剛被掛斷」）：**

| 選項 | 台詞（字數） | description |
|---|---|---|
| D1 ★推薦 | 「我以為掛掉就好了。」（10 字） | 沒說完的話，是壓抑系的典型語氣。落在轉折拍 |
| D2 | 「喂？」（2 字） | 明知對方不會回應還是問出口。最孤獨，適合懸置拍 |
| D3 | 「沒事了。」（4 字） | 說給自己聽的確認。與表情矛盾，張力最大 |
| — | 自由輸入 | 直接寫你要的台詞，我檢查字數與落點 |

**字數硬限（超過直接拒絕建單）**——完整表見 `sound-design.md` §6：

| 時長 | 中文上限 | 英文上限 |
|---|---|---|
| 5s | ≈8 字（**且不建議有對白**） | ≈6 詞 |
| 8s | ≈12 字 | ≈8 詞 |
| 10s | ≈15 字 | ≈11 詞 |
| 15s | ≈21 字 | ≈15 詞 |

**上限刻意保守**：實測模型實際語速約 5.7 字/秒（4 個字只用了 0.6 秒），
但那種速度聽起來像念稿不像演戲。**寧可短、寧可慢。**

**追問子題 G4b · 對白落點**：「這句話從第幾秒開始說？」
選項由節拍表生成，並**寫進提示詞的時間戳**（`around the third second she says quietly, '...'`）。
規則（`sound-design.md` §7）：
- **不上入戲拍**
- **轉折拍最強**（開口即換招）——**實測模型也自己落在轉折帶**
- 懸置拍＝自言自語，最孤獨
- 全片只有一句對白時，那一句就是落點，**不要浪費在開頭**

**用戶自定義的對白：逐字記進溯源表。** 有錯字或語病先回讀確認，**不要擅自改寫後假裝是用戶寫的**。

## H · 首幀表情與情緒方向衝突

**觸發條件**：參考圖中人物的表情與目標情緒不符。

**⚠️ 先問一個方向性問題（2026-09-26 新增）**：
首幀有表情時，**不要預設要把它消掉**。先判斷是「消」還是「留下」：

| 首幀狀態 | 目標極性 | 方向 |
|---|---|---|
| 有笑意／神情明亮 | **正向族** | **留下並放大**——笑是資產，不是要處理的誤差 |
| 有笑意 | 負向族 | 要處理：見 H1／H2 |
| 中性／嚴肅 | **正向族** | **要建立**——靠節拍（眼睛先亮），不靠負面詞 |
| 中性 | 負向族 | 不需處理，直接進浮起拍 |

**舊版這裡只處理「首幀有笑 → 要消掉」，等於在衝突清單裡就先假定目標是負向。**
那是隱形預設的入口之一，已補上另一半。

| 選項 | 標籤 | description |
|---|---|---|
| H0 ★推薦（正向時） | **留下並放大** | 首幀的笑意正好是正向族的起點。浮起拍寫「眼睛先亮」、轉折拍「笑開」、**懸置拍不收**。不要加任何 smile 負面詞 |
| H1 ★推薦（負向時） | 寫成敘事節拍 | 「淺笑緩緩褪去，化為憂鬱」。不與首幀對抗，反而多了一個轉折拍 |
| H2 | **換一個情緒方向族** | 若首幀的笑意難以褪去，改選**追憶系**或**溫柔系**（這兩族的收尾允許笑意殘留），**或直接改走正向族**——順著圖走比逆著改更省成本 |
| H3 | 忽略衝突 | 模型會兩邊拉扯，結果通常是表情僵硬 |
| H4 | 換圖重來 | 若首幀表情與目標差距過大（大笑 → 壓抑），換素材更省成本 |

切勿把目標情緒寫進負面詞（例如「不要笑」來壓首幀、或「不要悲傷」來壓首幀的愁）——
那會讓模型同時收到兩條矛盾的指令。**唯一的安全做法是把它寫成節拍。**
