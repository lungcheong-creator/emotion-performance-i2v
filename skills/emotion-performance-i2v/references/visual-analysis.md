# 劇照讀解與動態推理（Stage 0.2）

用途：把一張**靜態圖**讀成一場**正在發生的戲**。這是整條流程的地基——
沒有讀解，「情緒方向」的選項就只能從通用選單裡挑，那等於沒看圖。

**硬規則：讀解的所有結論都必須能指回畫面裡的具體東西。**
指不出來的，就是想像，寫進設計書會讓提示詞與素材對不上。

---

## 1 · 三步，順序不可顛倒

```
Step 1 讀數（跑腳本，拿到客觀數字）
   ↓
Step 2 讀解（把數字翻譯成人話，六個欄位）
   ↓
Step 3 動態推理（從這張圖推回「這是哪一瞬間」）
```

---

## 2 · Step 1 · 讀數

```bash
$PY \
  scripts/read_frame.py <圖片路徑> > frame_read.json
```

輸出的是**像素算出來的**事實：景別、構圖位置、光源方位、色調、景深、背景結構、人數推定、音場。

把 `observations` 逐條唸給用戶聽，把 `cautions` 當作訪談的必問項來源。
**不要跳過這一步直接目視讀圖**——目視會漏掉光源方位、景深、背景結構這些決定運鏡的關鍵事實。

**每次都會自動產出一張人眼複核圖 `<圖片名>_subject_check.jpg`（`--no-check-image` 可關）。**
紅框＝主體、綠框＝頭、黃框＝臉。**開它一眼再往下走。**

> **⚠️ 為什麼複核圖是強制的（2026-09-26 實測）**
> 秋景人像那張圖，膚色法把**右側石牆與落葉框成主體，人整個在框外**，而信心回報 **1.0**。
> 根因：駝色大衣（Cb/Cr 114.5/144.6）與她的臉頰（114.4/147.6）**幾乎完全相同**，
> 石牆與落葉也落進同一範圍 → **純顏色法原理上分不開**。
> 現在改為**臉部偵測優先**，並用「臉框內部色調是否像膚色」濾掉誤判。
> 判準看 `skin_region.source`：
>
> | source | 可信度 | 動作 |
> |---|---|---|
> | `face-haar` | 高（0.9） | 可直接用 |
> | `skin-blob` / `skin-blob-lowlight` | 中 | **必看複核圖**；`warm_false_positive_suspected` 標記出現時尤其 |
> | `gradient` | 低（0.3） | 幾乎等於猜的，若圖上其實沒人就別硬跑 |

**景別一律看 `shot_basis`。** 有臉時用**臉高占畫面百分比**（電影攝影的正確度量，
人體比例：臉高 ≈ 全身高 /9）；沒有臉時才退回膚色區高度。**兩者的數字不可互相比較。**
坐姿／倚靠會讓對應偏移，所以 `face_h_pct` 一律原樣輸出，由你在設計書裡校正。

三個框的用途不同，別混用（腳本已分開算）：

| 框 | 怎麼算 | 用來判斷 |
|---|---|---|
| `skin_region` | 臉部偵測的頭／身體框，或未擴張的膚色連通域 | **景別**與構圖位置 |
| `framed_reach` | 適度外擴（上 0.5／下 0.8／側 0.3） | 主體是否被畫面**邊緣切斷** |
| `subject_zone` | 主體框外擴 50%／20% | 光源、景深、背景的**取樣範圍** |

**依賴提醒**：臉部偵測需要 `opencv-python-headless`。沒裝也能跑（自動退回膚色法），
但暖色場景會踩到上面的坑。安裝：
`$PY -m pip install opencv-python-headless`

## 3 · Step 2 · 讀解（六個欄位）

| 欄位 | 要寫什麼 | 禁止寫什麼 |
|---|---|---|
| **主體** | 誰、幾人、景別、在畫面的哪一側。多人時**明確點出誰是主角與為什麼** | 「一個人」（太籠統） |
| **姿態** | 身體朝向、重心落在哪、支撐方式（站／坐／靠／半蹲）、肩線是否水平 | 「很放鬆」（那是判斷不是觀察） |
| **臉部** | 可見度、朝向（正臉／3-4 側／側臉／背面）、**依 §FACS 表回推的 AU 組合** | 「表情很傷心」（那是結論） |
| **視線** | 看鏡頭／看畫外哪一側／下垂／失焦、以及**視線與留白的關係** | 「眼神很有故事」 |
| **光與色** | 主光方位與軟硬、明暗對比、冷暖、飽和度、**光在她的哪一側臉上** | 「光線很美」 |
| **環境** | 背景結構密度、景深、可動的環境元素（見下）、畫外被裁掉什麼 | 「背景很電影感」 |

**可動環境元素的清單（讀解時逐項核對，有就記下來）：**

| 元素 | 畫面證據 | 能承擔什麼表演 |
|---|---|---|
| 髮絲偏移／衣角 | 髮絲不自然偏一側、衣角揚起 | **風**——內在動盪的外顯，最安全 |
| 雨的斜度 | 雨絲有角度 | 風向 + 時間感 |
| 水面／反光 | 有水、有玻璃、有金屬 | 光線推移、倒影中的第二層敘事 |
| 天空／霧／素牆 | 背景 `luma_std` < 22 | **光線推移**（雲影掃過），最乾淨的流動面 |
| 人群／街景 | 背景 `luma_std` > 45 | **人流對比**（她慢世界快） |
| 粒狀物 | 塵埃、雪、飛絮 | 空氣感、停滯感 |
| 車流／燈光 | 車道、霓虹、招牌 | 光點掃過、城市縱深 |

## 4 · Step 3 · 動態推理（這一節是這次升級的核心）

一張劇照不是「靜止的畫面」，是**被凍結的一瞬**。要從它反推運動。
逐項核對下面六條，答案是後面所有表演設計的依據。

### 4.1 六條推理線

| # | 推理線 | 問什麼 | 從畫面哪裡讀 |
|---|---|---|---|
| 1 | **動作的來處** | 她上一秒在做什麼？ | 未完成的動作：手停在半空、嘴微張、身體還在轉、重心不穩 |
| 2 | **動作的去處** | 下一秒她要去哪？ | 重心線的傾斜方向、肌肉的預備張力、視線的前方 |
| 3 | **張力線** | 畫面裡有什麼在互相拉扯？ | 對角線、對稱軸、視線引導線、前景遮擋物的斜切 |
| 4 | **焦點落點** | 鏡頭要你看哪裡？ | 景深最銳處、最亮處、最高飽和處、被框住處 |
| 5 | **畫外** | 畫面外有什麼？ | 被邊緣切斷的主體部位、她看的方向、留白側 |
| 6 | **時間感** | 這張圖是白天／黃昏／深夜？快還是慢？ | 光源高度與色溫、陰影長度、有無光源（霓虹／車燈） |

### 4.2 產出：「這張圖正在發生的動詞」

用**一句話**講完，句型固定：

> **她正在【做一個具體的動作】，因為【剛剛發生了什麼】，但【什麼擋著她】。**

**好**：
> 她正在把手機從耳邊放下，因為通話剛剛結束，但她還沒辦法把視線從車窗外那對情侶身上移開。

**壞**（沒有動詞、沒有前情、沒有阻礙）：
> 這是一個孤獨的氛圍，女主角顯得若有所思。

判準：如果這句話裡沒有任何**具體動作動詞**，就是沒讀進去，重讀。

### 4.3 前情三選一

從「動作的來處」生成**三個互相排斥的前情**，交給用戶選（見題庫 A 區）。
三個必須是不同的處境，不是同一件事的三種說法。

例（通話剛結束）：
1. **剛被告知壞消息**——她還沒反應過來，處於延遲期
2. **剛做出決定**——她已經決定了，正在承受決定的重量
3. **剛被掛斷**——她還在等對方回來，動作停留在「舉著」的殘餘

不同的前情 → 不同的節拍填充。這是「敘事性表演」的起點。

## 5 · 反幻覺規則（違反即整份讀解作廢）

1. **讀數裡沒有的東西不准寫進讀解。** 讀數說背景高度均勻，就不能寫「街上人來人往」。
2. **模特兒的身份、職業、關係不准編。** 可以說「她的視線落在畫外左側」，不能說「她在等她的丈夫」。
   前情只能作為**用戶可選的候選**提出，並標明是推定。
3. **AU 必須標為推定。** 寫「推定為 AU1 + AU15（壓抑的難過）」，不要寫成確定事實。
4. **不確定就寫不確定。** 「無法判斷是否為淺景深」比編一個答案有價值。
5. **低信心就說低信心。** `confidence < 0.45` 時必須把這條寫進讀解，並在交付時提醒人眼看縮圖。

## 6 · 主體類型判定樹（適用範圍擴大後必走）

範圍已擴到**任何人物照**，不同主體類型的處理完全不同。讀數出來後先歸類：

| 類型 | 判定依據 | 處理 |
|---|---|---|
| **A · 單人正臉／準正臉** | `significant_blobs` = 1，膚色居中且在上半 | 走完整流程，微表情是主力表演層 |
| **B · 側臉（3-4 側或全側）** | 膚色區偏窄 | 微表情只剩近側臉，**表演重心移到姿態與環境**；禁止大角度轉頭（會腦補遠側臉） |
| **C · 背影／背面** | 膚色極少或僅露頸部 | 表演只能靠**肩線、後頸、身體傾斜、髮絲**；禁止寫「她轉過頭來」（等於要求模型生成整張臉） |
| **D · 多人** | `significant_blobs` > 1 | **必問「誰是主體」**；必須用景深、光線或構圖把主角確立起來，否則模型會把注意力分散 |
| **E · 全景／遠景（膚色區 < 18%）** | 讀數 `height_pct` 小 | 微表情在大螢幕上是糊的 → **表演改由姿態、環境、光線承擔**；或先用收緊運鏡把主體放大 |
| **F · 無人物** | `skin_region` 為 null | 本 skill 不處理。改用環境敘事類的節拍（光線推移／焦點轉移），或換圖 |

**A–C 與 E 的差別是表演層的更換，不是流程的刪減。**六段節拍、時長摺疊、表演邏輯鏈全部照走，
只是「浮起」「轉折」這些拍的**內容**從微表情換成肩線／光線／環境流動。

## 7 · 讀解表模板（複製進設計書與 HTML）

```markdown
### 劇照讀解

**讀數**：1660×934 / 16:9 / 主體偵測信心 0.32（低光，需人眼複核）

| 項目 | 讀解 | 依據（畫面哪裡） |
|---|---|---|
| 主體 | 單人女性，近景（胸上），畫面中央略偏左 | 膚色區高 40%、中心 x 41% |
| 姿態 | 坐姿，上身正對鏡頭，肩線水平，重心沉在左胯 | 肩線與骨盆線 |
| 臉部 | 正臉，推定 AU1（眉內側上抬）+ AU15（嘴角下拉） | 眉型與唇線 |
| 視線 | 向下微偏右，與左側留白不成對 | 瞳孔方向、左側空景 |
| 光與色 | 主光來自右側偏硬，低對比、中性偏冷、飽和 0.18 | 讀數 light / tone |
| 環境 | 背景結構密集，環境清晰（非淺景深），無可動元素 | 讀數 background / depth_of_field |

**這張圖正在發生的動詞**
> 她正在把手機從耳邊放下，因為通話剛剛結束，但她還沒辦法把視線從車窗外移開。

**動態推理**
- 來處：右臂仍維持半舉的殘餘角度 → 上一個動作是「貼耳」
- 去處：重心偏左、視線向下 → 下一個動作是「垂下／卸力」
- 張力線：畫面右半（她與窗）實、左半空 → 張力指向右側畫外
- 焦點落點：臉部最亮，環境同樣清晰 → 鏡頭要你看臉，但環境沒有退場
- 畫外：上緣切斷頭頂、下緣切斷身體 → 畫外她仍在車內，空間持續
- 時間感：低光＋中低色溫 → 傍晚或陰天，慢

**推定前情（三選一，待用戶選）**
1. 剛被告知壞消息 2. 剛做出決定 3. 剛被掛斷

**風險**（來自讀數 cautions）
- 主體偵測信心 0.32：後製 21:9 前必須人眼看縮圖
```
